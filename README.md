# Composio 100-App Toolkit Research

A reproducible, evidence-first research project to assess 100 app integrations across 10 categories for agent-toolkit feasibility.

## Current status

This repository is being initialized. The 100-app list is a **research candidate set**, not a verified findings dataset. No app-specific auth/API/MCP claims or accuracy metrics should be treated as validated until official-source evidence and a human-reviewed audit are recorded.

## Research protocol

For each app, record: category and concise description; auth methods; whether credentials are self-serve or gated; API type and breadth; official MCP availability; toolkit implementation feasibility and blockers; and official evidence URLs with retrieval date.

Use official developer documentation, API references, OAuth/credential setup pages, and official MCP repositories as primary evidence. Mark unknowns explicitly. Separate observed facts, inferences, and unresolved questions. Do not infer an API's breadth from marketing copy alone.

## Validation

Use a stratified sample across categories and auth/API/MCP dimensions. Establish ground truth from cited official sources, calculate first-pass precision/recall only when labels exist, record corrections, and report post-correction metrics separately. Never present an unfilled audit worksheet as measured accuracy.

## Deliverables

- Structured 100-app inventory
- Evidence ledger and source links
- Research/verification scripts
- Pattern analysis and toolkit architecture recommendation
- Self-contained HTML report / GitHub Pages site

## Honest status

The initial commit establishes the project and its research standard. App-level research, audited accuracy, and published report are pending.
